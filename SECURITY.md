# Security Policy

## Supported Versions

Only the latest release receives security fixes. The image is published as
`ghcr.io/isdiegoalves/anzol:<version>`; upgrade to the newest tag to get a fix.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability reporting:
<https://github.com/isdiegoalves/anzol/security/advisories/new>. The project is maintained by
[@isdiegoalves](https://github.com/isdiegoalves). Do not open a public issue, pull request or discussion for a
suspected vulnerability.

Include, when you can:

- the affected version or commit;
- steps to reproduce, or a proof of concept;
- the impact you expect (what an attacker gains).

## Disclosure Process

- You get an acknowledgement within 7 days.
- The report is triaged and you get an assessment within 14 days.
- A fix is released as soon as it is ready, normally within 90 days of the report.
- The vulnerability is disclosed in a GitHub security advisory when the fix ships, crediting the reporter unless
  they ask otherwise. Please keep the details private until then.
